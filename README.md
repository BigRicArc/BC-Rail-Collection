# BC-Rail-Collection
A Newgrf for Openttd, adding content related to British Columbia, Canada.

### Installation
The bcrail.grf file should be added to the newgrf folder of your Openttd installation.

### Features
Features include one locomotive, one coach and a town name set.

- GMD GF6C Locomotive can be purchased after 1983.
- Bombardier BiLevel Coach's can be purchased after 1991.
- BC Place names can be activated by selecting British Columbia Town Names in level creation screen.

# Lore

### GMD GF6C

![GMD GF6C Photo](https://forums.firecrown.com/uploads/trains/original/2X/f/f972a688e212943d137290c9079953c29de81dea.jpeg)

An electric locomotive designed to haul coal from mines at Tumbler ridge through two very long tunnels in the Rockies to Prince George for transfer to the BC Rail main line.
Electric power was chosen due to the tunnels not having adequate ventilation for a diesel locomotive.

### Bombardier BiLevel Coach

![BiLevel Coach's at waterfront station](https://upload.wikimedia.org/wikipedia/commons/thumb/f/fb/West_Coast_Express_trains_at_Waterfront.JPG/1920px-West_Coast_Express_trains_at_Waterfront.JPG)

Theses passenger coaches are most frequently used on GO Transit trains in Ontario but are also the only type of passenger cars
on British Columbia's West Coast Express. These coaches have been around for awhile but in this newgrf they are only accessible in the 90s because that is when the West Coast Express got started. The West Coast express is the fourth largest operator of these coaches behind, Go Transit (Toronto), Metrolink (Los Angeles) and Sounder (Seattle).
