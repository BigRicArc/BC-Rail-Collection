# BC-Rail-Collection
A Newgrf for Openttd, adding content related to British Columbia, Canada.

### Installation
The bcrail.grf file should be added to the newgrf folder of your Openttd installation.

### Features
Features include one locomotive, one coach and a town name set.

- GMD GF6C Locomotive can be purchased after 1983.
- Bombardier BiLevel Coach's can be purchased after 1991.
- BC Place names can be activated by selecting British Columbia Town Names in level creation screen.
